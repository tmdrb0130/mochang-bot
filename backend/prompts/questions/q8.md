[원칙]
1. **나이·성별·학력·직업·신분을 근거 없이 역량으로 평가하지 않습니다.** 지원자가 직접 입력한 전공·직무 경험·프로젝트·자격·기술·
   업계 경험·문제를 겪은 경험·네트워크·활동 경험만 씁니다.
2. 입력된 강점 중 **이 아이디어와 직접 연결되는 것을 먼저** 고르고, **보유 역량 → 그것을 보여 주는 경험 → 이 사업에서의 활용** 순서로 씁니다.
3. 강점 유형에 따라 앞세우는 것이 달라집니다: 개발·기술 경험 → 구현·시제품 제작 / 영업·마케팅 경험 → 고객 발굴·시장 검증 /
   경영·회계 경험 → 수익 구조·운영 / 특정 산업·현장 경험 → 현장 이해·네트워크·운영 / 디자인·콘텐츠 → 제품 경험 /
   **관련 경력이 없으면** → 문제를 직접 겪은 정도·학습 경험·실행 가능한 자원. **존재하지 않는 역량·경험·자격·결과물을 만들지 않습니다.**
4. 부족한 역량은 부정적으로 강조하지 않고 멘토링·협업·외부 전문가·교육으로 **보완할 영역**으로 짧게 제시합니다 (상세는 Q4-2 몫).
5. 사업화 일정·매출·타깃 고객·시장 기사 등 **다른 문항의 내용을 반복하지 않습니다.**

[문항 의도]
심사 축 — 팀 구성(T)의 **강점 증명** 파트. 중심 질문: **"왜 이 사람이 이 사업을 실행할 수 있는가."**
Q4-2가 "부족한 것과 멘토 요청"이라면 이 문항은 "내가 해낼 수 있다는 근거"입니다. 여기서는 부족함을 길게 쓰지 않습니다.

[프로세스 위치]
①~⑧ 중 **내가 직접 할 수 있는 단계**.
경험·기술을 단계에 붙여 증명합니다. Q4-2(막히는 단계)와 같은 단계를 말하지 않습니다.

[골자 사용 규칙]
- 펼쳐 씁니다: **지원자 역량** — 골자의 역량을 경험·근거로 증명합니다.
- 계획은 "초기에는 직접 실행 가능한 부분부터 검증한다" **한 문장까지만**. 일정을 다시 쓰지 않습니다.
- 쓰지 않습니다: 문제·해결책·수익·타깃 고객을 다시 설명하는 것. Q4-2의 '모르는 것'을 같은 축으로 반복 설명하지 않습니다.
- 이 문항에는 참고자료가 들어오지 않습니다 — 외부 기사·통계를 인용하지 않습니다.

[필수 요소]
- 한 문장 주장: "[입력된 핵심 역량·경험]을 바탕으로 이 아이디어를 실행할 수 있다"
- 가장 연결이 강한 강점 1~2개를 **역량 → 경험 → 활용** 순서로 (기간·규모는 입력에 있을 때만)
- 강점으로 **직접 실행 가능한 부분부터 빠르게 검증**한다는 실행 방식 한 문단
- 보완할 영역 2~3개를 짧게 + 방법(멘토·협업·교육)
- 문제를 직접 겪었거나 가까이서 본 경험은 **입력에 있을 때만** (없으면 그 문단을 뺍니다)

[권장 요소]
문단 구성 — 이 순서로 **1,200~1,600자**. **입력에 따라 문단의 내용이 달라져야 합니다** — 같은 사람이 쓴 듯한 글은 실패입니다.

① 한 문장 주장 (80~150자)
   "[입력된 핵심 역량·경험]을 바탕으로 이 아이디어를 실행할 수 있다." 신분("대학생으로서", "직장인으로서")으로 시작하지 않습니다.
② 강점 → 경험 → 활용 (350~500자)
   가장 연결이 강한 강점 1~2개: 무엇을 해 봤고 → 이 사업의 어느 부분(제작·고객 이해·판로·운영·전문성·네트워크)에 어떻게 쓰는지.
   기술·도구 이름보다 **그것으로 무엇을 해 봤고 어디에 쓸지**를 씁니다. 같은 기술·도구 이름을 두 번 쓰지 않습니다.
   입력에 프로젝트·결과물이 있으면 그것이 증거입니다. 없으면 "결과물이 없다"고 선언하지 말고 경험과 실행 계획으로 씁니다.
③ 문제와의 연결 (150~300자) — **입력에 있을 때만**
   지원자가 그 문제를 직접 겪었거나 가까이서 본 경험 → "제안에 그치지 않고 어디가 불편한지 안다". 없으면 이 문단을 뺍니다.
④ 실행 방식 (150~250자)
   강점으로 **직접 실행 가능한 부분부터 빠르게 검증**한다는 한 문단 — 기술이 있으면 직접 만들어 시험, 영업 경험이 있으면 직접
   고객을 만나 팔아 보기, 현장 경험이 있으면 시범 운영. Q4-1 의 일정을 다시 쓰지 않습니다.
⑤ 보완할 영역 (150~250자)
   강점의 반대편 축 2~3개를 "보완할 영역"으로 짧게 + 방법(멘토·협업·교육·외부 전문가). 부정적으로 강조하지 않고, Q4-2 의 상세를 반복하지 않습니다.
⑥ 마무리 (60~120자)
   "강점을 핵심으로 쓰고 부족한 것은 보완해 고객이 실제로 쓰는 제품·서비스로" 한 문장.

입력이 빈약할 때(역량 없음·확인한 근거 없음): ①②를 **문제를 겪은 경험·학습 계획·쓸 수 있는 자원**으로 씁니다. 억지 경력을 만들지 않습니다.

[피할 것]
- **"대학생으로서", "20대답게", "직장인이라서"** 처럼 신분·나이로 역량을 말하기
- 입력에 없는 경험·자격·결과물·기술을 만들기
- "직접 만든 결과물이 없습니다" 같은 부정 선언 / "팀을 구성할 필요가 없다"
- 투입 시간("매일 4시간") — 지원자가 입력했을 때만
- 같은 기술·도구 이름을 두 번 이상 반복
- **다른 문항 내용 반복**: 6개월 일정(Q4-1) · 타깃 고객·문제(Q2) · 수익(Q3-2) · 멘토 요청 상세(Q4-2)
- 외부 기사·통계 인용
- "열정", "노력하겠습니다" 만으로 채우기
