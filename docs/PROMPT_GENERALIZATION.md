# 프롬프트 일반화 원칙 — 18개 사업 분야·모든 아이디어에 같은 품질

> 2026-09-02 14:4x 사용자 지시: "프롬프트가 특정 케이스에 과도하게 편향되면 안 됨". 프롬프트를 고치는 모든 작업(15·16·20·22·24·25·26 …)에 적용.

## 1. 대상 분야 (modoo.or.kr Q6 선택지 그대로, `App.jsx` FIELDS)

IT · 교육 · 금융 · 운영관리 · 네트워킹 · 농축/수산업 · 라이프스타일 · 마케팅/PR · 모빌리티 · 미디어/엔터테인먼트 · 바이오/의료 · 에너지/자원 · 유통/물류 · 임팩트 · 재무 · 프롭테크 · 하드웨어 · 기타

앱·플랫폼이 아닌 것도 많다: 오프라인 매장, 농산물 가공, 제조 하드웨어, 지역 임팩트 사업, 컨설팅. **"앱", "플랫폼", "기능", "사용자" 를 전제로 쓴 규칙은 편향이다.**

## 2. 규칙

1. **규칙 문장에 분야 어휘를 쓰지 않는다.** "이력서·면접·레시피·세탁" 같은 특정 소재가 `[필수 요소]`·`[피할 것]`·`[문단 구조]` 안에 들어가면 안 된다. 형태를 가리킬 때는 "제품·서비스", 기능은 "하는 일", 사용자는 "고객·이용자·수혜자".
2. **예시는 규칙과 분리**하고, 예시 소재는 **검증에 쓰는 아이디어와 다른 분야**에서 고른다. 예시가 한 파일에 2개 이상이면 서로 다른 분야(온라인/오프라인/제조 중 둘 이상). 라마는 예시 소재를 그대로 베낀다(작업 15 실측) — 예시는 짧게, 구조만 보이게.
3. **골든 예문은 프롬프트에 넣지 않는다.** 사용자가 준 예문(Q2_QUALITY 1절)은 사람 판정 기준일 뿐이다. 거기서 뽑는 것은 "구조·밀도·금지 패턴"이지 문장이 아니다.
4. **판별 규칙은 분야 중립으로 쓴다.** 예) "이미 있는 도구로 쉽게 되는 일은 문제가 아니라 기능이다" (○) / "ChatGPT 로 되는 질문 생성은 문제가 아니다" (×).
5. **오프라인·제조·1차산업에서도 성립하는지** 규칙마다 한 번 자문한다. "입력→처리→출력" 같은 소프트웨어 틀은 "재료→과정→결과물" 처럼 넓게 적거나 선택지로 둔다.
7. **지원자 인물상 전제 금지** — 나이·성별·학력·직업·신분으로 역량·문제 경험·행동을 추론하지 않는다. 입력된 전공·경험·자격·기술·네트워크·문제 경험만 쓴다(Q8_QUALITY 2절). "대학생으로서", "20대답게" 같은 서술은 입력에 그 말이 있어도 근거로 삼지 않는다.
6. 인테이크 카드 보기도 같다 — 보기 문구가 소프트웨어 전제("개발 팀 구성", "기능 설계")로만 나오면 편향. 분야별로 "만든다·기른다·연다·계약한다"가 다 나올 수 있게.

## 3. 검증 세트 — 프롬프트 변경은 **분야가 다른 아이디어 3개 이상**으로 실호출해 통과해야 한다

| # | 분야 | 아이디어 (고정, 문구 그대로 사용) | 형태 |
|---|---|---|---|
| A | IT | 이력서와 지원 직무를 기반으로 맞춤형 면접 질문을 생성하고 답변·말투·시선·속도를 분석해 피드백하는 AI 면접 코칭 서비스 | 온라인 SaaS |
| B | 유통/물류 | 동네 세탁소들이 공동으로 쓰는 새벽 세탁물 수거·배달 기사 매칭 플랫폼 | B2B 플랫폼 |
| C | 농축/수산업 | 소규모 딸기 농가가 공동으로 쓰는 저온 저장·직거래 택배 포장 센터 | 오프라인 시설·1차산업 |
| D | 바이오/의료 | 독거 고령자용 복약 시간 알림·미복용 시 보호자 통보 스마트 약통 | 하드웨어+서비스 |
| E | 라이프스타일 | 캠핑장 빈자리 실시간 알림과 당일 취소분 할인 예약 서비스 | 소비자 앱 |
| F | 임팩트 | 경력 단절 여성이 동네 아이 돌봄을 시간 단위로 맡는 지역 협동조합 | 오프라인·비앱 |
| G | 교육 | 초등 저학년 대상 주 1회 방문 실험 키트 수업 | 오프라인 서비스 |

- 작업마다 최소 **A + (C 또는 F 중 하나) + 1개 더** — 소프트웨어가 아닌 것을 반드시 포함.
- 결과 표는 분야별 한 줄씩(문항·글자수·지적 항목 통과 여부). 한 분야에서만 좋아지고 다른 분야가 나빠지면 실패.
- 사용자 판정용 문장은 분야별로 1건씩 그대로 로그에.
