# 작업 30 — Q4-1(아이디어를 어떻게 사업화할 계획인가요) 품질: 골든 예문 기준 구조 재설계

> 2026-09-02 15:1x 사용자 피드백. 구현: 세션3, `q4_1.md`. 일반화 원칙 적용 — 예문·소재·숫자는 판정 기준일 뿐 프롬프트에 넣지 않는다.
> Q4-1 의 중심 질문: **"무엇을 만들 것인가"가 아니라 "어떻게 검증하고, 고객을 모으고, 유료화까지 갈 것인가."** 단계마다 무엇을 검증하는지가 보여야 한다.

## 1. 골든 예문 (사용자)

> 저희는 MVP 개발, 고객 검증, 초기 사용자 확보, 유료화 검증의 순서로 사업화를 진행할 계획입니다. 1년 이내 베타 사용자 500명을 확보하고, 이 중 최소 30명의 유료 전환을 달성하여 초기 사업성을 검증하는 것을 목표로 합니다.
>
> 초기 2개월 동안에는 핵심 기능을 중심으로 MVP를 개발할 계획입니다. 사용자가 이력서와 지원 직무 또는 채용 공고를 입력하면 개인 맞춤형 예상 질문을 생성하고, 음성으로 답변한 내용을 분석하여 피드백을 제공하는 기능을 우선 구현하고자 합니다. 초기에는 답변 내용, 발화 속도, 답변 길이, 반복 표현 등 측정이 명확한 요소를 중심으로 분석하고, 이후 시선 등 비언어적 요소까지 단계적으로 확대할 계획입니다.
>
> MVP 개발 후에는 취업 및 이직 준비생 20명을 대상으로 인터뷰와 사용성 테스트를 진행하여 질문의 적절성, 분석 결과의 유용성, 반복 이용 의향과 유료 이용 의향을 검증할 예정입니다. 단순 만족도뿐 아니라 실제 재사용 여부와 유료 이용 의향을 주요 판단 기준으로 삼아 서비스의 핵심 기능을 개선하겠습니다.
>
> 초기 사용자는 대학 취업 커뮤니티, 취업 스터디, 온라인 취업 커뮤니티, K-Digital Training 및 취업 교육과정 수료생 등을 대상으로 무료 베타 테스트 참여자를 모집하여 확보할 계획입니다. 이후 사용자 피드백과 이용 데이터를 바탕으로 기능을 개선하고, 기본 기능은 무료로 제공하면서 반복 면접 시뮬레이션, 상세 분석 리포트, 이전 연습 결과 비교 등의 기능을 유료화하여 실제 결제 가능성을 검증하겠습니다.
>
> 창업활동자금은 개발 비용 60%, 마케팅 및 사용자 확보 20%, 인건비 10%, 기타 운영 비용 10% 수준으로 활용할 계획이며, 초기에는 서비스 완성도와 고객 검증에 우선적으로 투자하고자 합니다.
>
> 가장 중요한 사업 가정은 사용자가 범용 생성형 AI보다 본 서비스의 면접 시뮬레이션과 분석 기능에서 충분한 가치를 느끼고 실제 비용을 지불할 것인지입니다. 따라서 초기에는 기능 확장보다 반복 이용률과 유료 전환 가능성을 집중적으로 검증할 계획입니다.
>
> 개인 대상 서비스의 사업성이 확인된 이후에는 대학 취업지원센터, 취업 교육기관, K-Digital Training과 같은 교육 프로그램을 대상으로 기관용 면접 훈련 및 결과 관리 기능을 제공하여 B2B 시장으로 사업을 확장하고자 합니다.

## 4. 분야 일반화 점검

- C(딸기 농가)·F(돌봄 협동조합)·G(실험 키트): "MVP" 는 시범 운영·소량 생산·첫 계약이고, "유료화" 는 첫 판매·회원 모집. ②⑤ 의 표현이 소프트웨어 전제가 아닌지 확인.
- 검증 세트 A 3건 + C + F + B. 통과 조건: 500/30 같은 숫자가 **아이디어 간 동일하게 반복되지 않음**, 1차/2차 구분 존재, 행동 지표 존재, 범용 SNS 단독 0, 확장 축이 형태와 일치, 참고자료 인용 0, 이물 0, 1,400~1,800자.

## 5. 작업 22 ③ 에 대한 정정

"500명·30명·60/20/10/10 상용구 블랙리스트"는 **원인이 프롬프트 예시** 였으므로 블랙리스트 대신 예시 삭제로 해결한다. 22 ③ 은 **매출·원가 상용구(1만 원·5천 원·1억)** 에만 적용.
