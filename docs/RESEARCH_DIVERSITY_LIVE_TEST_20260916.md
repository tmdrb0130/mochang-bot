## 발견한 문제와 추가 보완

첫 수정본 실행에서는 수익 문항의 배정 근거가 0개인데도 모델이 추가 검색어로 빈 배열을 반환했다. 프롬프트의 빈 배열 허용 조건을 명확히 하고, 출처가 2곳 미만인데 모델이 검색어를 내지 않거나 JSON 파싱에 실패하면 기존 상한 안에서 문항 관점의 보완 검색 1건을 수행하도록 보완했다.

그 뒤 실제 공통 조사 결과를 그대로 재사용해 수익 문항만 재실행했다. 이번에는 모델이 검색어 2개를 만들었고 서로 다른 기사 2곳에서 근거를 확보했다. 따라서 이 표의 수정 후 결과는 공통·배경·차별점은 첫 실행, 수익은 보완 후 재실행 결과를 합친 것이다. 전체를 다시 실행한 독립 표본은 아니다.

## 검색됐지만 채택되지 않은 논문

수정본은 KCI의 「프랜차이즈의 제품 유형과 매출 및 판매공간 시설의 상관관계 분석 — C 반찬가게 프랜차이즈를 중심으로」를 수집했지만, 추출 단계에서 사용 가능한 근거 사실이 남지 않았다. 논문이 검색되었다는 것과 실제 초안의 근거로 사용되었다는 것은 다르다.

- 실제 초안 본문은 생성하지 않았다. 이번 검증 범위는 검색 → 자료 수집 → 사실 추출 → 문항별 작성 프롬프트에 전달할 근거 배정까지다.

- 수정본에도 전국 음식 업종 수처럼 아이디어보다 범위가 넓은 통계와 2017년 시장 자료가 남았다. 출처 다양화는 확인했지만 자료 관련성·최신성까지 충분하다고 보기는 어렵다.
