## 2. 세션3 — 단계 B: 문항별 근거 배분과 경쟁 조사 (작업 33, 신규)

지금은 문항 9개가 같은 facts 를 받고(2단계) 번호 순서로 2건씩 나눈다(`references_for`, 임시). 이것을 **문항 역할 기반 배분**으로:

1. 문항별 조사 각도 정의 (분야 중립):
   - Q2: 문제의 크기·고객 행동 변화·현황 통계 (KOSIS·뉴스·논문)
   - Q3-1: **기존 대안·경쟁 서비스의 기능**, 기술·방식 동향 (뉴스·웹문서·KCI·KIPRIS)
   - Q3-2: 유사 서비스 과금·가격대·지불 행태·시장 규모 (뉴스·KOSIS·ECOS)
   - Q4-1·Q4-2·Q8·Q10: 근거 없음. Q1: 없음.
2. `followup_queries.md` 가 문항별 각도로 보완 검색어를 만들게 하고(지금은 "부족한 각도"만), facts 에 `angle: problem|competitor|pricing|trend` 를 붙인다. `references_for(question_id)` 는 **각도 일치 facts 우선 → 남는 공통 facts 를 키워드 매칭으로 → 문항 간 중복 없이** 배분. 같은 fact 는 한 문항에만.
3. 경쟁사: facts 에 서비스명이 있으면 `source_kind: competitor`. 골자 `differentiators` 는 이 facts 로만. 근거 없는 경쟁사 이름은 골자·본문 모두 금지(Q3_1_QUALITY 4절).
4. 근거가 0건인 문항은 프롬프트에 "[웹 참고자료 없음 — 통계·기관명·서비스명을 쓰지 않는다]" 를 넣어 지어냄을 막는다(지금은 섹션이 그냥 빠짐).
5. 검증: 세트 A·C·F 조사 → 문항별 배정 facts 표(제목·각도·출처)를 로그에, 사람이 주제 일치 판정(세션1).

## 4. 세션2 — 생성 후처리 모듈 (작업 22 + 27, 신규 파일)

`backend/pipeline/postprocess.py`: `def refine(text: str, ctx: dict) -> tuple[str, dict]` — ctx = {question_id, limit, target_range, idea, outline, answers, references, team, other_texts?}. 규칙(순서대로, 각각 report 에 건수):

| # | 규칙 | 방법 |
|---|---|---|
| ① | 이물 문자 | 한자·가나·태국·베트남 성조 등 비한글·비ASCII 문자가 든 **문장** 을 표시 → 호출자가 그 문장만 재생성(1회), 실패 시 삭제 |
| ② | 지어낸 수치 | 인터뷰·설문·N명·금액·%·억/만 이 든 문장의 숫자가 idea·answers·references·outline 어디에도 없으면 → 문장 삭제(짧은 문항은 재생성). "가정" 표기가 있어도 삭제 |
| ③ | 매출·원가 상용구 | "1만 원·5천 원·1억" 류 단위경제 문장 삭제 |
| ④ | 1인칭 통일 | team=="팀원 없음" 이면 "저희" → "저"(조사 처리), 아니면 반대. 골자 voice 기준 |
| ⑤ | 통계 재인용 | 같은 (출처+수치) 가 한 문항에 2회 이상이면 두 번째부터 삭제; 다른 문항(other_texts) 에 이미 있으면 이 문항에서 삭제 |
| ⑥ | 재진술 첫 문장 | Q1·Q3-1 이외 문항의 첫 문장이 idea/outline.solution 과 4-gram Jaccard≥0.5 → 삭제 |
| ⑦ | 이어쓰기 중복 | extend 결과에서 기존 본문과 Jaccard≥0.5 문장 제거, 남는 게 없으면 무효 |
| ⑧ | 금지어 | "데이터 판매", "고유한 가치", "혁신적", "AI 기반" 단독 등 → 문장 삭제 또는 호출자에 재생성 신호 |
| ⑨ (27) | 한도 초과 | limit 초과면 자르지 않고 `needs_compress=True` 반환 → 호출자가 `shorten.md` 로 1회 압축, 그래도 넘으면 **문단 끝**에서만 자름. 짧은 문항은 작업 21 그대로 |
| ⑩ | 분량 미달 | target 하한 미만이면 `needs_extend=True` (호출자가 1회 이어쓰기 → ⑦ 적용) |

- 순수 함수·모델 호출 없음. `tests/test_postprocess.py` 에 규칙별 케이스 + 세션1 실측 원문(`docs/measurements/*.json`) 을 픽스처로 "전/후 건수" 회귀 테스트.
- 완료 후 세션3 이 `generate_one`/`extend_one` 끝에 `refine()` 한 줄 연결 + 재생성 루프(최대 2회).
