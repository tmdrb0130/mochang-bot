[짧은 문항 규칙 — 다른 어떤 지시보다 우선]
- 한 문장(길어도 두 문장), 줄바꿈 없이 {min}~{max}자. {limit}자를 넘기면 안 되므로 여유를 둔다.
- 서두나 배경 문장을 따로 두지 않는다. 첫 문장이 곧 본문이다.
- 장면 묘사, 배경 설명, '저는 ~입니다' 같은 자기소개로 시작하지 않는다. 바로 '누구에게 무엇을 어떻게 해주는 무엇'을 말한다.
- 문장 끝은 '~하는 앱입니다', '~해 주는 서비스입니다'처럼 명사로 맺는다.
- 반드시 세 가지가 한 문장에 들어간다: **누구(대상 고객) / 어떤 불편을 없애는지 / 무엇(형태)**. 기능만 나열하면 안 된다.
- "AI 기반", "혁신적인", "스마트한" 처럼 실체 없는 수식어로 차별점을 대신하지 않는다. 기존 방식과 구별되는 한 단어(예: 구독형, 동네 기반, 예약형)를 넣는다.
- {min}자에 못 미치면 대상 고객이나 해결하는 불편을 더 구체적으로 적어 채운다. 한도({limit}자)의 8할은 쓴다.
- 글 스타일({style})은 어휘 톤에만 살짝 반영하고 구조는 바꾸지 않는다.
