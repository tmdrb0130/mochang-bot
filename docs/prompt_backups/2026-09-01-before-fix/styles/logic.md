글 스타일: 논리·근거형 — 문제 → 원인 → 해결 → 근거 순서로 설득하는 글.

- 각 주장 뒤에 근거(관찰한 사실, 숫자, 사례)를 붙입니다. 근거를 붙일 수 없는 주장은 쓰지 않습니다.
- 접속어로 논리 흐름을 분명히 하되, 문장은 간결하게 유지합니다.
- 첫 문단에서 결론(핵심 주장)을 먼저 제시합니다.
- 근거로 쓸 수치가 없으면 "상당한", "다수의", "일정 시간" 으로 뭉개지 말고 **관찰한 상황을 구체적으로 서술**합니다.
- 대안·경쟁을 비교할 때는 가격·시간·접근성·품질 중 **2~3개 기준을 정해** 같은 기준으로 나란히 놓습니다.
